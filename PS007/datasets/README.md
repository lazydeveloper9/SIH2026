# Dataset Information

This folder contains information and sample data related to the datasets used for training the project's machine learning models.

## Dataset Sources

Dataset links and references will be added here.

## Folder Structure

* `sample/` — Small sample data for testing and understanding the dataset structure.
* Full datasets are not uploaded directly to the repository if they are too large.

## Dataset Usage

Each dataset used in the project should include:

* Dataset name
* Source link
* Purpose
* Data format
* License
* Preprocessing requirements
